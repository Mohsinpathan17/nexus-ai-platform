## Architecture and safeguards

- `GET /api/examples/{id}` reads a saved build. It never starts inference.
- `POST /api/examples/{id}` builds only one of the three server-owned briefs. Visitors cannot submit arbitrary anonymous prompts or choose models.
- Atomic leases prevent duplicate builds and stale writes. Saved builds are reused rather than charging inference for every visitor.
- The existing shared daily generation budget remains 10 attempts; each example has a maximum of three failed attempts. Provider quotas still apply. Viewing and interacting with a saved build does not consume an AI generation slot.
- Failures display a real error; no fake progress stream or fallback app appears.
- API credentials stay in Worker secrets. Responses contain generated source and public provenance only.
- Previews have an opaque origin, `sandbox="allow-scripts allow-forms"`, and a nonce-based CSP. No same-origin privilege, top navigation, popups, external connections, frames, objects, or form network submissions are allowed. `allow-forms` is necessary for local JavaScript submit handlers; CSP `form-action 'none'` blocks network submission.
- Source rendering is escaped React text, not injected into the parent document.
- Mobile shows the app before the brief/build record. Larger preview height exposes the runway result; internal scrolling remains available for longer apps. Reduced-motion loading indicators stay static.
