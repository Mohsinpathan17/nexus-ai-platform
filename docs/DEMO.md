# NEXUS Demo Script

1. Say: “NEXUS is an engineering control plane, not a chatbot. It investigates, gathers evidence, patches a sandbox, validates the change, evaluates risk, and stops before production.”
2. Run the checkout HTTP 500 mission.
3. Show the 3D agent topology and live timeline.
4. Open Evidence Graph: logs + DB + code converge on the root cause.
5. Open Code Diff: show the minimal patch.
6. Open Security & Policy: tests pass, no critical/high findings, production requires human review, destructive DB actions are blocked.
7. Return to Command Center and approve the release gate.
8. Close with: “The differentiator is the system around the model: tools, state, evidence, policy, evaluation, observability and human control.”
